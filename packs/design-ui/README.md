# design-ui

Interface craft from first sketch to finished build. Impeccable (shape, critique, audit, polish, animate) with its four review and documentation agents, plus the better-* rule sets for accessibility, color, layout, type, UI and UX writing.

```bash
./install.sh design-ui
./install.sh design-ui --plugins   # also installs: interfaces@interfaces
```

## Agents

- `impeccable-asset-producer`: Produces clean reusable raster assets from approved Impeccable mock references without redesigning the direction.
- `impeccable-documenter`: Records DESIGN.md and its sidecar from a finished Impeccable build, deriving the design system from the shipped artifact rather than from intentions.
- `impeccable-finish-reviewer`: Reviews a finished Impeccable build against its direction contract, the approved comp, and the chosen world's quality bar, returning an ordered list of material
- `impeccable-manual-edit-applier`: Applies leased Impeccable live manual copy-edit batches to source and returns canonical Apply results.
