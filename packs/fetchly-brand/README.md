# fetchly-brand

Everything that makes work look and sound like Fetchly. Brand tokens (CSS and W3C JSON), color and type rules, the case cover generator, and theme tooling. Install this pack first: other packs assume these tokens.

```bash
./install.sh fetchly-brand
```

## Skills

| Skill | What it does |
|---|---|
| `brand-guidelines` | Applies Anthropic's official brand colors and typography to any sort of artifact that may benefit from having Anthropic's look-and-feel. Use it when brand color |
| `fetchly-case-cover` | Create looping UI-motion cover videos for Fetchly case studies (fetch.ly/case-studies) with Remotion, in the style of Paperpillar's Dribbble "App UI Motion Expl |
| `fetchly-knowledge` | Fetchly Labs brand knowledge base — company info, design system tokens, content strategy, and website patterns. Use this skill whenever working on anything re |
| `theme-factory` | Toolkit for styling artifacts with a theme. These artifacts can be slides, docs, reportings, HTML landing pages, etc. There are 10 pre-set themes with colors/fo |
