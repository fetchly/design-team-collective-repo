## Voice & Tone

- **Bold & confident** — Direct, punchy, startup energy. "We build what others can't."
- Avoid corporate jargon and fluff
- Use short, declarative sentences for headlines
- Body copy can be conversational but always substantive
- Headlines often use ALL CAPS for impact
- Section labels use spaced uppercase tracking (e.g., `OUR STORY`, `SERVICES`)
- Accent phrases use serif italic (Besley) for contrast

## Layout Rules

When building Fetchly pages, use exactly **two max-widths** for content containers:
1. **Wide:** `max-w-[1280px]` with `px-8 lg:px-16` — used for all sections
2. Content narrowing is done with grid fractions (e.g., `lg:w-2/3` or `lg:w-1/2`) inside the wide container, never with a different outer max-width

This prevents content from "jumping" as users scroll between sections. All section headers, body text, and grids left-align to the same edge.

### Color Alternation Pattern
- Page sections alternate between `bg.page (#FFFEFA)` and `bg.subtle (#F6F5F1)`
- Cards on page bg use `bg.card (#FFFFFF)` or `bg.subtle`
- Cards on subtle bg use `bg.page (#FFFEFA)`

### Button Hierarchy
- **Primary actions** (CTAs, important buttons): `malibu/default (#60E5FB)` background with `fg.primary (#0B0B0D)` text
- **Emphasis/dark context buttons**: `malibu/darkest (#1F444B)` background with white text
- **On dark backgrounds**: `malibu/default (#60E5FB)` background with dark text
- Hover states: one step lighter in the malibu scale

## About Us Page Architecture (SMB Funnel-Mapped)

The About Us page follows the SMB Advertiser Needs funnel:

| Section | Funnel Stage | Purpose |
|---------|-------------|---------|
| 1. Hero + Stats | **Awareness** | Bold headline, value prop, key metrics |
| 2. Story + Values | **Awareness** | Founding story, company values |
| 3. Tech Stack + Projects | **Discovery** | Technologies, case studies, client logos |
| 4. Services | **Consideration** | Service grid, differentiator banner |
| 5. Mid-page CTA | **Conversion** | Clear call to action before testimonials |
| 6. Testimonials | **Customer Relationship** | Social proof with star ratings |
| 7. FAQ | **Conversion (support)** | Address objections |
| 8. Newsletter | **Retention** | Email capture for non-ready visitors |
| 9. Footer | **Conversion (final)** | Contact, locations, links |

### Hero Layout (Based on Figma design)
Two-column split layout:
- **Left:** Brand name top, large all-caps headline (96px responsive), description paragraph, showcase card (offset, bottom-left)
- **Right:** CTA button (top-right), showcase card (offset down)
- Showcase cards use `bg.emphasis (#1F444B)` with white text, 16px radius
