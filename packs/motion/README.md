# motion

Micro interactions and motion graphics. Production CSS transitions, a motion token polish pass, UI effect libraries, generative p5.js art, Slack GIFs, screen videos, and the micro-interaction-designer agent. REFERENCE.md inlines every motion skill, including the Figma and Webflow plugin ones.

```bash
./install.sh motion
./install.sh motion --plugins   # also installs: interfaces@interfaces,figma@claude-plugins-official,webflow-skills@webflow-skills
```
