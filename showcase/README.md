# Showcase

Finished design work built with the packs in this repo, kept here so the team can open it, learn from it and reuse it. Each folder is one client project with plain HTML pages: open its `index.html` in a browser, no build step.

| Project | What's inside | Built with |
|---|---|---|
| [`armada-power/`](armada-power/) | Motion studies for three resident app screens (Options A, B, C), plus bento studies of app sections, charts and controls, with an Opus and a Fable build of the same brief | `motion` pack: stageshow method, `fetchly-bento`; `design-ui`: impeccable |
| [`spyderco-v2-visuals/`](spyderco-v2-visuals/) | Animated bento of the Spyderco V2 home page and mega menu | `motion` pack: `fetchly-bento` |

To add a project: one folder per client, an `index.html` entry page, a README listing each page and its source (Figma file, claude.ai artifact), and a note on any sample data.
