# Spyderco V2 Visuals

An animated bento of the Spyderco V2 home page and mega menu: hero search, lock spotlight, steel coupon, exploded knife, icon nav, gift card and collection tiles, each tile doing one interaction.

Open `index.html` in a browser.

## Stack

- Plain HTML, CSS and JavaScript in a single page
- Google Fonts: DM Sans
- Local assets: hero echo SVG, scratched steel texture, Spyderco wordmark

Exported from a claude.ai artifact on 4 Nov 2026.
